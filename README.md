# Brain2Win Prototyp

Minimaler HTML/CSS/JS-Prototyp der Brain2Win-Plattform.

## Inhalt
- `index.html` – Landing Page mit Erklärung des Anti-Pay2Win-Konzepts
- `games/tictactoe.html` – Voll funktionsfähiges Tic-Tac-Toe (Hotseat, 2 Spieler)
- `games/connect4.html` – Voll funktionsfähiges 4 Gewinnt / Connect Four (Hotseat)
- `games/chess.html` – Platzhalter für Schach

## Deployment
1. Die Ordnerstruktur so lassen.
2. Auf beliebigen statischen Hoster hochladen (Cloudflare Pages, Vercel, Netlify, GitHub Pages, eigener Server…).
3. Domain `brain2win.com` auf den Root zeigen lassen.
4. Fertig – sofort spielbar.
